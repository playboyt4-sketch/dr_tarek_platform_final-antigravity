## 1. 📋 Overview & Architectural Scope (نظرة عامة والهدف)
هذا المستند يمثل المرجع الهندسي الشامل والنهائي لتنفيذ شاشة **مراجعة طلبات الانضمام المعلقة للفرقة الأولى** (`Grade- Grade one pending requests`) في لوحة تحكم المنصة التعليمية (**Tarek el araby Platform - Web Dashboard**).
تتيح هذه الشاشة للمشرف أو المدرس استعراض وفرز طلبات الطلاب الجدد الراغبين في الانضمام للفرقة الأولى، ومراجعة أرقام هواتفهم، ونوع الأجهزة المسجلين بها (`Device Binding Security`)، وتاريخ تقديم الطلب لاتخاذ قرار القبول أو الرفض وعرض إيصال السداد.

## 7. 📋 Pending Requests Table (جدول طلبات الانضمام المعلقة)
* **اسم الفريم الحاوي الرئيسي:** `# STUDENTS LIST`
* **الموقع على الشاشة:** `X: 78px`, `Y: 420px`
* **الأبعاد الخارجية:** العرض `1120px` × الارتفاع `390px` (Fixed ومضبوط داخل حدود الشاشة 800px).
* **انحناء الحواف:** `Corner radius: 16px`.
* **الخلفية والحدود:** خلفية بيضاء ناصعة `#FFFFFF`، إطار ناعم `1px solid #E5E7EB`.
* **الظل (Elevation):** `Drop Shadow: X: 0, Y: 4, Blur: 20, Spread: 0, rgba(0, 0, 0, 0.05)`.
* **قص المحتوى (Clip Content):** مفعّل (`true`).
* **إعدادات الـ Auto layout:** `Vertical Flow`, `Gap: 8px`, `Alignment: Top-Left`.

### أ) شريط عناوين الأعمدة الثابت (Sticky Table Header):
* **اسم الفريم الداخلي:** `> [] Table Header`
* **الأبعاد:** `W: 1120px`, `H: 40px`
* **الخط المعتمد:** `Google Sans Flex`، حجم **`14px`**، وزن **`Medium (500)`**، لون رمادي هادئ **`#6B7280`**.
* **أعمدة الجدول الستة وتوزيعها:**
  1. رقم المسلسل: `No.` (محاذاة يسار)
  2. اسم مقدم الطلب: `Student Name` (محاذاة يسار)
  3. رقم الهاتف المسجل: `Phone Number` (محاذاة يسار / اتجاه LTR)
  4. نوع الجهاز المسجل: `Device` (لتأمين ربط الأجهزة Device Binding)
  5. تاريخ تقديم الطلب: `Request date` (تاريخ: `D/M/YYYY`)
  6. إجراء المراجعة: `Action` (زر الفحص: `View`)
* **الخط الفاصل السفلي للهيدر:** طبقة `Line 16` بعرض `1120px`، سمك `1px`، ولون `#E5E7EB`.

### ب) حاوية صفوف الطلبات والسكرول (Scrollable Requests Rows):
* **اسم الفريم الداخلي:** `Frame 74` (أو فريم الصفوف التفاعلي)
* **الأبعاد:** العرض `1120px`، ارتفاع ثابت محصور مع سكرول رأسي `Overflow: Vertical`.
* **قص المحتوى:** مفعّل (`Clip content: true`).
* **ارتفاع الصف القياسي:** `H: 48px` مع خط فاصل رمادي خفيف `#F3F4F6`.
* **هيكل بيانات الصف الواحد:**
  * `No.`: رقم مسلسل من خانتين (`01.`, `02.`, `03.`...).
  * `Student Name`: خط `Google Sans Flex`، حجم `14px`، وزن `Regular 400`، لون أسود داكن `#111827`.
  * `Phone Number`: رقم هاتف الطالب المصري (مثل: `01101011588`)، لون `#374151`.
  * `Device`: نوع جهاز الطالب لتأكيد البايندينج (مثل: `I phone 15 pro`)، لون `#4B5563`.
  * `Request date`: تاريخ وصول الطلب (مثل: `3/9/2026`)، لون `#6B7280`.

### ج) زر إجراء المراجعة (`View / Review Action Button`):
* **اسم الطبقة:** `button/view`
* **الأبعاد المضبوطة بالـ Auto layout:**
  * العرض: `W: 88px`
  * الارتفاع: `H: 32px`
* **المحاذاة والهوامش:**
  * المحاذاة: منتصف أفقي ورأسي (`Center-Center`).
  * الهامش الأفقي: `14px`.
  * الهامش الرأسي: `6px`.
  * الاستدارة: `Corner radius: 9999px` (كبسولة دائرية كاملة).
* **النمط اللوني:**
  * التعبئة (Fill): برتقالي الفرقة الأولى `#F59E0B` (100%).
  * النص: كلمة `View` بخط `Google Sans Flex`, حجم `12px`, وزن `Medium 500`, لون أبيض `#FFFFFF`.
* **الوظيفة التفاعلية:** عند الضغط عليه يفتح نافذة منبثقة تفاعلية (`Payment Receipt & Request Dialog`) لمراجعة صورة إيصال فودافون كاش / إنستاباي وبيانات الجهاز، مع زري "قبول الطلب" و"رفض الطلب".
