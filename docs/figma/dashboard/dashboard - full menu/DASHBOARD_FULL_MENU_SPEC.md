## 5. 🎬 Interaction & Navigation Flow (منطق الانتقال والتفاعل)

1. فتح القائمة:
   * عند النقر على `the menu ICON` في الصفحة الرئيسية:
   * تفتح شاشة `# dashboard - full menu` بحركة Smart Animate ناعمة:
     * يتحول الخطان الأفقيان إلى علامة X في نفس موضعها (80, 24).
     * تنبثق عناصر القائمة بانسيابية وهدوء.
2. إغلاق القائمة والعودة:
   * عند النقر على علامة X:
   * تعود الشاشة فوراً لـ `# dashboard - home` ويعود الزر لشكله الأفقي.
3. التوجيه للأقسام (Route Dispatching):
   * النقر على أي فرقة (مثل `Grade One`): يغلق المنيو ويوجه المستخدم لشاشة الفرقة المحددة (`# Grade One (students)`).
   * النقر على عناصر الإدارة (مثل `Subscription` أو `Admins`): يوجه المستخدم لشاشة الإدارة المعنية.
