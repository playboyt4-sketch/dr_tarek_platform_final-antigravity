# 🎨 Education App — Design System Specification

هذا الملف يمثل المرجع الهندسي الشامل والوحيد لنظام التصميم (Design System) الخاص بالمنصة التعليمية.
يجب على الذكاء الاصطناعي والمهندسين الالتزام الكامل بهذه الرموز (Tokens) والقواعد عند بناء أي واجهة في Flutter.

---

## 1. 🏛️ Core Design Philosophy (فلسفة التصميم)
* **القاعدة الحيادية (Base):** الأبيض والأسود النقيان للشاشات العامة وشاشات تسجيل الدخول والترحيب.
* **الانغماس اللوني للفرق (Semantic Theming):** عند تسجيل دخول الطالب، تتحول خلفية التطبيق بالكامل إلى لون فرقته الدراسية المحددة.
* **النمط البصري العام:** زجاج سائل عصري (Liquid Glassmorphism) مع شفافيات ناعمة وتمويه خلفي (Background Blur).
* **النظام الطباعي:** خط `Google Sans Flex` باستخدام وزني `Regular` و `Thin` فقط.
* **شبكة الأبعاد:** نظام مضاعفات الرقم 8 (8-Point Grid).

---

## 2. 🎨 Color Tokens & Modes (نظام الألوان والأوضاع)

### أ) الوضع العام (Default Mode - قبل تسجيل الدخول)
* `bg-canvas`: `#FFFFFF` (خلفية الشاشة البيضاء)
* `item-surface`: `#F3F4F6` (خلفية الحاويات والبطاقات الفاتحة)
* `text-primary`: `#111827` (النصوص والعناوين الأساسية - أسود داكن)
* `text-secondary`: `#6B7280` (النصوص الفرعية والملاحظات)

### ب) ألوان الفرق الدراسية (Semantic Grade Modes)

| الفرقة | اللون الأساسي للخلفية (`bg-canvas`) | لون النصوص (`text-primary`) | لون أسطح الكروت والأزرار (`item-surface`) |
| :--- | :--- | :--- | :--- |
| **الفرقة الأولى (Grade 1 - Yellow)** | `#F59E0B` (أصفر كهرماني دافئ) | `#111827` (أسود داكن) | `rgba(0, 0, 0, 0.12)` (أسود شفاف 12%) |
| **الفرقة الثانية (Grade 2 - Blue)** | `#1D4ED8` (أزرق ملكي كلاسيكي) | `#FFFFFF` (أبيض ناصع) | `rgba(255, 255, 255, 0.15)` (أبيض شفاف 15%) |
| **الفرقة الثالثة (Grade 3 - Green)** | `#15803D` (أخضر غابي هادئ) | `#FFFFFF` (أبيض ناصع) | `rgba(255, 255, 255, 0.15)` (أبيض شفاف 15%) |
| **الفرقة الرابعة (Grade 4 - Red)** | `#DC2626` (أحمر ياقوتي راقٍ) | `#FFFFFF` (أبيض ناصع) | `rgba(255, 255, 255, 0.15)` (أبيض شفاف 15%) |

## 3. 🔤 Typography System (النظام الطباعي)
* **Font Family:** `Google Sans Flex` (أو `Google Sans`)
* **Allowed Weights:** `Regular` (400) و `Thin` (100/300) فقط.

| الرمز (Style Token) | الحجم (Font Size) | مسافة السطر (Line Height) | الوزن (Weight) | الاستخدام المعتمد |
| :--- | :--- | :--- | :--- | :--- |
| **`title/large`** | `28px` | `36px` | `Regular` (400) | العناوين الرئيسية ورأس الصفحات والترحيب |
| **`title/medium`** | `20px` | `26px` | `Regular` (400) | نصوص الأزرار، عناوين المواد، والبطاقات |
| **`body/regular`** | `14px` | `20px` | `Regular` (400) | نصوص المتن وحقول الإدخال والأسئلة |
| **`body/thin`** | `14px` | `20px` | **`Thin`** (100) | العبارات الوصفية الأنيقة والملاحظات الهادئة |
| **`caption/small`** | `12px` | `16px` | `Regular` (400) | التواريخ، مواعيد المحاضرات، والشارات |
| **`logo/signature`** | — | — | Script / Cursive | توقيع وشعار `Tarek el araby` (أصل رسومي) |

## 4. 📐 Spacing & Dimensions (المسافات والأبعاد)
* `spacing/4`: **4px** (فراغ دقيق بين الأيقونة والنص)
* `spacing/8`: **8px** (مسافة بين العناوين وشروحها)
* `spacing/16`: **16px** (المسافة القياسية لهوامش الشاشات والـ Padding)
* `spacing/24`: **24px** (المسافة الفاصلة بين الكروت المتتالية)
* `spacing/36`: **36px** (المسافات الواسعة وفصل الأقسام)

---

## 5. 🔘 Border Radius Scale (استدارة الزوايا)
* `radius/sm`: **8px** (الشارات والبطاقات الصغيرة)
* `radius/md`: **16px** (كروت المواد، القوائم، وحقول الإدخال)
* `radius/full`: **9999px** (الأزرار البيضاوية بالكامل / Capsule Buttons)

---

## 6. 🧩 Master UI Components (المكونات الأساسية)

### 1) زر الإجراء الرئيسي (`❖ button/primary`)
* **الأبعاد:** عرض كامل `345px` × ارتفاع `56px`.
* **استدارة الزوايا:** `radius/full` (`9999px`).
* **الخط:** `title/medium` (`20px` Regular).
* **الحالات (Variants):**
  * **`Style = Glass` (فوق خلفيات الفرق):**
    * Background Fill: `rgba(255, 255, 255, 0.20)`
    * Border Stroke: `1px` بلون `rgba(255, 255, 255, 0.30)`
    * Effect: `BackdropFilter` (Blur: `24px`)
    * Text Color: `#FFFFFF` (أو `#111827` للأصفر)
  * **`Style = Solid` (فوق الشاشات البيضاء):**
    * Background Fill: `#1D4ED8` (أزرق ملكي 100%)
    * Text Color: `#FFFFFF`

### 2) كارت المادة والدروس (`❖ card/course-item`)
* **الأبعاد:** عرض `345px` × ارتفاع `60px` (أو Hug المحتوى مع Padding `20px` أفقي و `16px` رأسي).
* **استدارة الزوايا:** `radius/md` (`16px`).
* **الخط:** `title/medium` (`20px` Regular).
* **الخامة (Liquid Glass):**
  * Background Fill: `rgba(255, 255, 255, 0.15)`
  * Border Stroke: `1px` بلون `rgba(255, 255, 255, 0.25)`
  * Effect: `BackdropFilter` (Blur: `20px`)
  * Text Color: `#FFFFFF`
